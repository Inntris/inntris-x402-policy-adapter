# KYA OS delegated authority evidence

This directory contains deterministic public test evidence for release target `v0.4.0`. It proves
local request proof, signed delegation, financial binding and Decision Envelope behaviour with
public test identities only.

Run `pnpm evidence:kya:generate` and `pnpm evidence:kya:verify` under the pinned Node and pnpm
versions. This evidence does not prove live funded settlement, production deployment, certified
custody, KYA partnership or third party endorsement.
